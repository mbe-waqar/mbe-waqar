### 🏆 Featured Project — Genipilot

An LLM-powered browser automation platform built on a **dual-agent architecture** (Orchestrator + Playwright Agent):

- ✅ ~85% task completion across 10+ web task categories
- ⚡ ~70% reduction in manual task time
- 🔐 Human-in-the-loop safety layer for OTP / password / 2FA via real-time WebSocket streaming
- 🖥️ Two FastAPI services on shared MongoDB (auth/dashboard + AI orchestration)
- 👁️ Manifest V3 Chrome extension using GPT-4o Vision for OCR and UI detection
