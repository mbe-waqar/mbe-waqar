### 🏆 Featured Project: GeniPilot

Started as my final-year project and now runs in production at Createch.

**Final-year version ([open-source repo](https://github.com/mbe-waqar/Genipilot--IntelligentAssistantForWebTaskAutomation))**
- ✅ Dual-agent architecture: LangGraph orchestrator + Playwright executor
- ⚡ ~85% task completion across 10+ web task categories, ~70% less manual task time
- 🔐 Human-in-the-loop handoff over WebSocket for OTPs, 2FA and passwords
- 👁️ Manifest V3 Chrome extension using GPT-4o vision for UI element detection

**Production version (private, [Chrome Web Store](https://chromewebstore.google.com/detail/genipilot-ai-browser-assi/daioplgahodkjlcahabfididfdbkljml))**
- 🔁 Rebuilt on an OpenAI Agents SDK orchestrator and a browser-use executor driving real Chrome over CDP
- 📈 Runs 15+ social media accounts with 25+ posts a day, plus continuous feed engagement and commenting
- 📸 Instagram Graph API publishing, Apify comment research, PostgreSQL storage
